# Childcare Management System

##  Project Overview
This web application helps daycare providers manage daily operations such as child enrollment, attendance tracking, staff scheduling, billing, and parent communication.

##  Developed by
**Rusul Al-Turfi**  
Course: CIS375 – Human-Computer Interaction  
Professor: Rahat Zafar

##  Features
- Secure login for Admin, Staff, and Parents
- Child and Staff profile management
- Attendance tracking
- Staff scheduling calendar
- Billing and invoice system
- Parent-staff messaging
- Responsive design for desktop and mobile

##  Technology Stack
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Python with Flask
- **Database**: SQLite (development), PostgreSQL (production)
- **Authentication**: Flask-Login, bcrypt
- **Deployment**: Heroku or PythonAnywhere
